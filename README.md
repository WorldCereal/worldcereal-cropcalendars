# worldcereal-cropcalendars

- dev folder contains the baseline datasets from Phase I plus the updates. It also contains the source of the planting and harvesting dates. These datasets are used to run the LSP model for the paper.
- GitHub doesn't allow uploading >25 Mb files so we are using Terrascope: /data/worldcereal/data/cropcalendars/Phase_II/worldcereal_cropcalendars/
- /reference_layers contains the vector layers developed for the Baseline points.
- /expanded_datasets contains the expanded points (Baseline + AgERA5 + WC Active Croplands) to train the weighted XGBoost model.
